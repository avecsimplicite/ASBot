# ASBot

> **Tu prends le relais de ce service ? Commence par [GUIDE-RELEVE.md](GUIDE-RELEVE.md).**
> Il explique ce qu'est ASBot, comment changer un message ou un bouton, comment publier,
> quels comptes portent quoi, et les pièges connus. Aucun mot de passe n'est dans ce dépôt public.

ASBot est un panneau qui s'ouvre dans Zoom, à côté de la vidéo, pour le groupe Avec Simplicité de
Narcotiques Anonymes : il montre les postes de service du mois (feuille « Posts mensuels ») et
publie d'un clic, dans le chat de la réunion, les messages habituels (première étape,
7e Tradition, serviteur à l'affichage, serviteur à l'animation).

- Page en ligne : https://asbot.pages.dev (publiée par Cloudflare Pages depuis la branche `main`)
- Messages des boutons : [`public/messages.json`](public/messages.json)

Un outil pour converser dans une séance Zoom qui peut nous répondre et agir selon la volonté de la conscience de groupe

## Intentions

* entrer en relation avec cet element complexe de créer un outil avec ce type de technologie
* Voir ce que ce type d'outil contribue à créer dans une conscience de groupe
